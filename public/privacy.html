Privacy & Data Controls

This page summarizes the privacy controls implemented by the personalized account layer. It is a product-information page and should be reviewed with your final legal/privacy policy before production launch.

Public and guest use

Public market, economic, reliability and learning features can remain available without signing in. Guest workspace data is stored in the browser unless a feature explicitly saves data elsewhere.

Authenticated workspace

When Supabase account services are configured and you sign in, supported workspace data is mirrored to rows tied to your authenticated user ID. Row Level Security restricts those rows to that user.

ArthaMind personal context

Personal data sources are opt-in. Income/expenses, budgets/goals, paper portfolio, learning progress and conversation saving can be independently enabled or disabled. Disabled sources are not retrieved for personalized ArthaMind requests.

Data controls

  • Export accessible account/workspace data.
  • Delete saved AI conversation history.
  • Delete financial workspace data with typed confirmation.
  • Delete the account through a server-side authenticated deletion flow when configured.

Credentials and secrets

Raw passwords are handled by the authentication provider. Administrative database credentials and provider API secrets must remain server-side and are not exposed through VITE-prefixed frontend variables.
