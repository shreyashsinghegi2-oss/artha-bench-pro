# Raksham scam detector (deployment folder)

A small API and web page that tell scam messages from genuine ones (English, Hindi, Hinglish). It is a **separate Vercel project** from the ArthaMind app: root directory `scam-detector`, its own URL.

- `api/index.py`: FastAPI app. `GET /api/health` (includes a built-in self-check) and `POST /api/predict` (1 to 50 messages of up to 2,000 characters).
- `api/_lite.py`: scores messages with NumPy only. It reproduces scikit-learn's TF-IDF features and logistic regression, so the function needs no scikit-learn, no SciPy and no pickle.
- `model/`: the exported model (vocabularies, weights, thresholds, evaluation summary). Generated by `raksham-export` in the training project; the training data is not part of this repository.
- `public/index.html`: the demo page.

Set `RAKSHAM_API_KEY` in the Vercel project's environment variables to require an `x-api-key` header on `/api/predict`.

## What the numbers mean

On message templates the model had not seen: about 93% of scam templates caught and 80% of genuine templates left alone (ROC AUC 0.975). The training messages are synthetic and template-written, so these scores do not measure accuracy on real messages. Salary and premium notices are sometimes flagged as scams. Scam type is a weak hint (about 27% accurate). A verdict is a warning, not proof.
